# VESSARI

Основной бренд/компания. Продукт: мужские (и теперь женские) часы, кожаные
сумки и ремни.

Каналы продаж:
- **Wildberries** — основной маркетплейс, аналитика через MPStats (см. переписку и `docs/` в корне репозитория — общие факты о бизнесе живут в `docs/project-memory.md`, здесь не дублируются).
- **Авито** — новый канал, см. [`Авито-продажи/CLAUDE.md`](Авито-продажи/CLAUDE.md).

Если появятся другие направления/каналы VESSARI — заводить отдельную подпапку
рядом с `Авито-продажи/`, по тому же принципу.
