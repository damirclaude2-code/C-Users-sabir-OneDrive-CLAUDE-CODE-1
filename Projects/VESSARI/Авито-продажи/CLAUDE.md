# Контекст: Авито-продажи VESSARI

Этот файл действует только внутри папки `Projects/VESSARI/Авито-продажи/` —
поверх общих правил из корневого `CLAUDE.md` (они по-прежнему действуют:
безопасность файлов, credentials, skill pack, agentic triage, proof loop).

## Что это за направление

Новый канал сбыта для уже существующего товара VESSARI (тот же поставщик/склад,
что и на Wildberries) — площадка **Авито**, а не маркетплейс типа WB/Ozon.

Ассортимент на Авито:
- часы мужские;
- часы женские;
- сумки кожаные;
- ремни кожаные.

## Чего пока не хватает (заполнить по мере работы)

- [ ] Есть ли уже аккаунт на Авито, или его нужно завести (регистрацию делает пользователь сам, я не завожу аккаунты);
- [ ] Артикулы/фото товаров, которые пойдут на Авито;
- [ ] Ценовая политика: цены как на WB, или отдельно для Авито (учитывая, что на Авито нет комиссии маркетплейса, но есть своя логика продвижения объявлений);
- [ ] Регион/город размещения объявлений;
- [ ] Формат доставки — самовывоз, встреча, отправка ТК.

## Как работать в этой папке

- Не путать с аналитикой Wildberries/MPStats — та работа живёт отдельно, здесь только Авито-специфика (тексты объявлений, цены под Авито, переписка с покупателями, статистика просмотров/откликов).
- Credentials (если для Авито понадобится API или интеграция) — по общим правилам, в `credentials.md` в корне репозитория, не здесь.
