# Контекст: Грузоперевозки

Этот файл действует только внутри папки `Projects/ГРУЗОПЕРЕВОЗКИ/` — поверх
общих правил из корневого `CLAUDE.md` (безопасность файлов, credentials,
skill pack, agentic triage, proof loop — по-прежнему действуют).

## Что это за направление

Отдельное от VESSARI направление. Есть свой грузовой автомобиль и водитель —
работа состоит в поиске грузов под свой транспорт (не диспетчерская работа на
чужой транспорт).

## Чего пока не хватает (заполнить по мере работы)

- [x] Тип и грузоподъёмность автомобиля — см. [`автомобиль.md`](автомобиль.md);
- [x] Базовый регион/город — Казань;
- [x] Биржи грузов — уже есть аккаунт на АТИ.su (логин/пароль пока не переданы — см. `credentials.md`, когда будут);
- [x] Предпочтительные направления/маршруты — загрузка Казань, выгрузка Казань, либо разбег до 50 км от Казани на любом из плеч; другие города списком пока не переданы;
- [x] Требования к грузу — без опасных грузов (ADR); оплата только безналичная без НДС (с НДС не берём); других ограничений по типу груза нет — берём любой груз, подходящий по весу и кузову.

## Структура папки

- `автомобиль.md` — характеристики своего грузового автомобиля;
- `биржи-грузов/` — заметки/выгрузки по конкретным биржам, найденные подходящие грузы;
- `маршруты/` — часто используемые направления, расстояния, ориентиры по ставкам.

## Как работать в этой папке

Не путать с VESSARI — это независимый бизнес, здесь только грузоперевозки
(поиск груза, расчёт рейса, документы, биржи).

При поиске и подборе грузов на биржах: и загрузка, и разгрузка — либо город
Казань, либо в радиусе до 50 км от Казани (разбег допустим на любом из двух
плеч маршрута — на загрузке, на разгрузке, или на обоих сразу). Варианты, где
загрузка или разгрузка дальше 50 км от Казани, не предлагать.

Не берём опасные грузы (класс ADR). Оплата — только безналичная без НДС.
Варианты с оплатой через НДС, наличными или без указания способа оплаты —
не предлагать как готовые, уточнять отдельно.
