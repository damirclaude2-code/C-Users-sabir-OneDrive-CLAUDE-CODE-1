# Контекст: Грузоперевозки

Этот файл действует только внутри папки `Projects/ГРУЗОПЕРЕВОЗКИ/` — поверх
общих правил из корневого `CLAUDE.md` (безопасность файлов, credentials,
skill pack, agentic triage, proof loop — по-прежнему действуют).

## Что это за направление

Отдельное от VESSARI направление. Есть свой грузовой автомобиль и водитель —
работа состоит в поиске грузов под свой транспорт (не диспетчерская работа на
чужой транспорт).

## Чего пока не хватает (заполнить по мере работы)

- [ ] Тип и грузоподъёмность автомобиля;
- [ ] Базовый регион/город, откуда обычно стартуют рейсы;
- [ ] Какие биржи грузов уже используются (АТИ.su, Trans.ru, Deliver и т.п.) или нужно завести аккаунт — регистрацию делает пользователь сам;
- [ ] Предпочтительные направления/маршруты (если есть);
- [ ] Требования к грузу (тип, вес, есть ли ограничения по кузову).

## Структура папки

- `биржи-грузов/` — заметки/выгрузки по конкретным биржам, найденные подходящие грузы;
- `маршруты/` — часто используемые направления, расстояния, ориентиры по ставкам.

## Как работать в этой папке

Не путать с VESSARI — это независимый бизнес, здесь только грузоперевозки
(поиск груза, расчёт рейса, документы, биржи).
