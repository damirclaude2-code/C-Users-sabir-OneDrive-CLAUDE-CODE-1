# Яндекс — проверены все варианты, ни один не подходит под вашу машину

Дата проверки: 13.09.2026

## Итог сразу: платформа Яндекс не подходит вашему транспорту

Проверил все грузовые направления Яндекс Доставки (включая страницу именно
по Казани) и отдельный B2B-продукт «Магистрали». Ни один вариант не
рассчитан на 5-тонный рефрижератор — везде либо слишком низкий лимит по
весу, либо это вообще не биржа для отдельного перевозчика.

## 1. Яндекс Доставка — «Грузовой» тариф по Казани

Источник: [dostavka.yandex.ru/for-driver/personal-cargo-kazan](https://dostavka.yandex.ru/for-driver/personal-cargo-kazan/)

Требования к машине:
- Грузоподъёмность — **до 3,5 тонн** (ваша машина 5 т — не проходит)
- Кузов — только **тент, будка или цельнометаллический фургон** (реф не
  упомянут вообще)
- Год выпуска не ранее 2002 для регионов (для справки)

Это, по сути, аналог «Яндекс Такси» для газелей — платформа рассчитана на
лёгкий коммерческий транспорт, не на 5-тонные рефрижераторы.

## 2. Яндекс Доставка — «Межгород»

Источник: [dostavka.yandex.ru/for-driver/long-distance](https://dostavka.yandex.ru/for-driver/long-distance/)

- Грузоподъёмность — **от 300 кг до 4 тонн** (тоже ниже ваших 5 т)
- Кузова по категориям S/M/L — обычные фургоны, реф не упоминается
- Максимальный маршрут — 1000 км, средняя дальность у примеров 200–700 км

Тоже не подходит по весу и по типу кузова.

## 3. Яндекс Магистрали

Источник: [dostavka.yandex.ru/magistral](https://dostavka.yandex.ru/magistral/)

Это **не биржа для отдельного перевозчика**, а корпоративное облачное
ПО (TMS) для логистических компаний — управление заказами, документами и
деньгами «в едином окне», с торгами внутри системы конкретной компании.
Индивидуальному владельцу одной машины зарегистрироваться напрямую и
увидеть грузы там нельзя — это инструмент для компаний с собственным парком
перевозчиков, не публичная площадка.

## Вывод

Яндекс как платформа — мимо в этот раз: ни грузоподъёмность, ни тип кузова
(реф) нигде не совпадают с вашей машиной. Единственный сценарий, где Яндекс
мог бы быть полезен — если бы у вас была машина до 4 тонн без требований по
температуре, но это не ваш случай.

Актуальные рабочие направления остаются прежними: **Магнит («Сельта»)**,
**Ozon («Вози Ozon»)**, **X5/«Чижик»** и **ATI.su** — там требования по
весу и кузову реально совпадают с вашим транспортом.
