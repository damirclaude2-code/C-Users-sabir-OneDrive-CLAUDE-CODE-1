# Словарь маршрутизации: SIMPLE или COMPLEX

Этот словарь помогает Claude Code (и любой автоматизации, которая вызывает
gateway) понять, в какую дорожку отправлять задачу — не по названию модели,
а по формулировке запроса.

## SIMPLE-триггеры

- "простая задача";
- "классифицируй";
- "распарси";
- "вытащи поля";
- "сделай JSON";
- "коротко суммируй";
- "выбери категорию";
- "маршрутизируй";
- "быстро проверь".

## COMPLEX-триггеры

- "сложная задача";
- "используй сильную модель";
- "нужен proof loop";
- "проверь архитектуру";
- "напиши production-решение";
- "сделай финальную редактуру";
- "проверь качество";
- "нужна надёжность";
- "используй Claude/Codex".

## Главное правило

Если запрос влияет на **деньги, продакшен, юридические документы, код,
публичный контент или стратегическое решение** — не отправлять его в SIMPLE
без явного разрешения пользователя. По умолчанию такие задачи идут в COMPLEX.
