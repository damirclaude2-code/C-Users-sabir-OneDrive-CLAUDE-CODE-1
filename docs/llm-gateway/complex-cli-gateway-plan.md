# COMPLEX gateway

## Назначение

COMPLEX-дорожка — для задач, где качество важнее скорости и где ошибка стоит
дорого:

- архитектура продукта;
- сложные кодовые задачи;
- финальная редактура важных текстов (презентации, документы для внешних людей);
- стратегический анализ;
- контентные цепочки, где важнее качество, чем скорость;
- задачи, где нужен proof loop (см. раздел "Proof loop для сложных задач" в `CLAUDE.md`).

## Рекомендуемая архитектура

```text
OpenAI-compatible client
        ↓
internal CLI gateway
        ↓
Claude Code CLI
        ↓ если лимит или ошибка
Codex CLI
        ↓ если лимит или ошибка
paid/API fallback только если он явно нужен
```

## Важные ограничения — прочитать перед запуском

- это **внутренний контур** для владельца проекта (или команды), а не публичный API для перепродажи;
- **не выставлять** такой gateway в интернет без авторизации, rate limit и логирования;
- для production-продукта, который используют внешние клиенты, часто честнее использовать официальный API с понятным SLA, а не CLI-обёртку;
- для внутренних автоматизаций и собственной команды это хороший способ использовать уже оплаченные плоские подписки там, где они уже есть;
- смысл COMPLEX-дорожки — не платить по API-счётчику за каждый токен, когда задача может идти через Claude Code CLI или Codex CLI в рамках подписки.

## Где взять доступ

Claude Code и Codex CLI используют твою уже существующую подписку/логин —
отдельных API-ключей для них не нужно. Единственный секрет, который может
понадобиться — `CLI_GATEWAY_TOKEN` (токен для доступа к самому internal
gateway, если он вызывается извне, например из n8n). См.
[`credentials-checklist.md`](credentials-checklist.md).
