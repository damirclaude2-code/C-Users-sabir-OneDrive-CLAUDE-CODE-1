# Project memory

Этот файл хранит долговечные факты о проекте, которые Claude Code должен помнить между сессиями.

## Как добавлять запись

Добавляй только то, что будет полезно будущей работе:

- факты о продукте, компании, аудитории или пользователях;
- важные ограничения и договоренности;
- словарь терминов проекта;
- ссылки на канонические документы;
- recurring context: что Claude Code часто забывает или понимает неверно.

Не добавляй сюда временные задачи, черновики, личные мысли и разовые обсуждения.

## Долговечные факты

### 2026-08-27 — Чего Claude Code физически не может делать на этой машине

- Факт: нет доступа к курсору/мыши реального рабочего стола Windows
  (только к браузерной панели предпросмотра). Нельзя перетащить иконку,
  кликнуть в стороннем приложении, ответить на диалоговое окно программы.
  Правка реестра Windows под правку позиции иконок и подобные "системные
  настройки" — запрещена как категория действий в принципе, даже с
  разрешения пользователя.
- Почему важно помнить: если пользователь просит "подвинь иконку", "нажми
  кнопку в программе X" — не пытаться найти обходной путь через реестр
  или иные системные хаки, а сразу честно сказать про ограничение и дать
  пошаговую инструкцию для ручного выполнения.
- Где связано: `bugs-and-gotchas.md` — не заводили отдельную запись,
  т.к. это не баг, а стабильное ограничение окружения.

### 2026-08-27 — Рабочий стол пользователя живёт в OneDrive, не в C:\Users\sabir\Desktop

- Факт: реальный видимый Рабочий стол — `C:\Users\sabir\OneDrive\Рабочий стол`.
  Обычный `C:\Users\sabir\Desktop` существует как папка, но не отображается
  пользователю в Проводнике как Рабочий стол.
- Почему важно помнить: любая просьба "положи на Рабочий стол" должна идти
  именно в OneDrive-путь, иначе пользователь не увидит результат.
- Где связано: `bugs-and-gotchas.md` (первый случай, когда это всплыло).

### 2026-08-30 — Формат credentials.md — свой, не шаблонный

- Факт: `credentials.md` использует структуру `### [Сервис] / Тип / Значение /
  Где используется / Дата добавления / Комментарий` — это НЕ формат
  `SERVICE_API_KEY=`, который предлагают некоторые установочные промпты.
- Почему важно помнить: при новых установках (новые сервисы, новые ключи)
  добавлять записи в существующем формате, не переписывать файл под шаблон
  промпта.
- Где связано: `../credentials.md`.
