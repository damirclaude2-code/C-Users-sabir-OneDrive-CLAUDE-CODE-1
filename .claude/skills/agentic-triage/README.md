# Agentic Triage

Этот skill нужен, чтобы Claude Code перед нетривиальной задачей коротко
оценивал масштаб, риск и безопасный следующий шаг.

## Простая идея

Сначала понять задачу, потом действовать.

## Когда включается

Автоматически перед задачами, где есть риск:

- изменить несколько файлов;
- сломать дизайн или код;
- удалить или перенести что-то важное;
- работать со свежими фактами;
- трогать ключи, деньги, доступы, деплой или внешние системы;
- менять поведение агента, skill, prompt, router, MCP или workflow.

## Ручные фразы

- "сначала оцени задачу";
- "проверь задачу перед действием";
- "сделай agentic triage";
- "сделай триаж задачи";
- "оцени риск";
- "безопасно сделай";
- "не ломай, сначала проверь";
- "сначала план";
- "proof loop".

## Короткий формат

```text
Task class:
Reason:
Protocol path:
Risk:
Safe next step:
```

## Главное

Agentic triage идет до skill-router.

Triage отвечает: "насколько задача рискованная и можно ли действовать сразу?"

Skill-router отвечает: "какой навык нужен для выполнения?"
