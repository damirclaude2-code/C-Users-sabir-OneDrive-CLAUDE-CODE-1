# Overnight Task Queue

Навык для безопасной очереди задач, которую Claude Code обрабатывает без
присутствия человека (например, ночью).

## Подходит для

- длинных задач, разбитых на маленькие независимые пункты;
- работы "пока я сплю / отошёл";
- разбора backlog по одному пункту за раз.

## Главное правило

Один пункт очереди = один запуск Claude Code = один пакет доказательств.
При ошибке или неопределённости очередь останавливается, а не продолжает.

## Что важно знать в этом проекте

- рабочие логи и статус очереди лежат в `.claude/queue/` и не попадают в git;
- правила маршрутизации — в `.claude/rules/overnight-task-queue-routing.md`;
- запуск очереди — только по явной просьбе пользователя.

## Примеры вызова

```text
Поставь очередь задач на ночь: обработай эти пять пунктов по одному.
```

```text
Запусти автономную очередь и утром дай отчёт, что сделано и где остановилась.
```
