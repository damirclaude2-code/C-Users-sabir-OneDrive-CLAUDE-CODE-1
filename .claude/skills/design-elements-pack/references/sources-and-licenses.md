# Sources and Licenses

Этот pack собран без платных зависимостей.

## Локальные HWAI источники

Pack опирается на локальные наработки HWAI:

- `website-builder-suite/templates`
- `website-builder-suite/design`
- `tokens-pipeline`
- `DESIGN_HARNESS`

Из них взяты:

- anti-slop rules;
- structural patterns;
- template registry logic;
- понимание, чем заменить Tailwind Plus.

## Open-source источники

Для бесплатного baseline используются такие источники:

- `shadcn/ui` — MIT
- `HyperUI` — MIT
- `daisyUI` — MIT

## Что здесь не используется

- Tailwind Plus
- платные Figma kits
- закрытые шаблонные библиотеки

## Зачем это важно

Пользователь должен получить stack, который:

- можно использовать бесплатно;
- можно повторить;
- не сломается из-за отсутствия платной подписки;
- не запрещает переработку под свои проекты.
