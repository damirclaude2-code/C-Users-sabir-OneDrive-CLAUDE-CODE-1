# Pattern Selection

Этот файл помогает быстро выбрать правильный structural route.

## Шаг 1. Определи тип артефакта

- `cold landing` — человек почти ничего не знает, сначала нужно объяснить.
- `warm landing` — человек пришел с контекстом, можно быстрее идти к value.
- `pricing page` — нужно помочь self-selection и убрать friction.
- `comparison page` — нужно показать различия и помочь выбору.
- `sales slide` — нужно быстро провести по одной сильной мысли.
- `explanatory slide` — нужно объяснить механизм или идею.
- `dashboard explainer` — нужно структурировать плотную информацию.

## Шаг 2. Определи главную задачу

- объяснить;
- снять непонимание;
- показать выгоду;
- доказать;
- снять возражения;
- сравнить;
- довести до действия.

## Шаг 3. Выбери маршрут

### Cold landing

`hero -> proof -> problem -> solution -> value props -> objection handling -> CTA`

### Warm landing

`hero -> value props -> proof -> CTA`

### Pricing page

`pricing intro -> plan cards/table -> comparison -> FAQ -> CTA/contact sales`

### Comparison page

`headline -> when each option fits -> comparison table -> differentiation -> CTA`

### Sales slide

`main claim -> proof -> 3 supporting points -> next step`

### Explanatory slide

`problem/context -> mechanism -> example -> takeaway`

## Когда выбирать `designer`, а не этот pack

Если у пользователя уже есть:

- готовый экран;
- готовый слайд;
- существующая секция;

и задача звучит как "улучши", "переделай", "что тут не так", тогда сначала
больше подходит `designer`.
