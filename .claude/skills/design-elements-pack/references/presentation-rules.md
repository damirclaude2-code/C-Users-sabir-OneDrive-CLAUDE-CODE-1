# Presentation Rules

Этот файл нужен, чтобы `design-elements-pack` работал не только для веба, но и
для презентаций.

## Главный принцип

Слайд — это не маленький лендинг.

У слайда почти всегда:

- одна главная мысль;
- один главный proof;
- один следующий шаг или вывод.

## Что должно происходить на хорошем слайде

- смысл считывается быстро;
- заголовок действительно ведет весь слайд;
- supporting blocks не спорят с headline;
- текста не слишком много;
- глаз понимает, куда смотреть первым, вторым и третьим.

## Хорошие structural patterns для слайдов

### 1. Main claim + proof

Лучший базовый паттерн для:

- сильного урока;
- sales slide;
- one-message explainer.

### 2. Problem -> mechanism -> takeaway

Хорош для обучающих и explanatory slides.

### 3. Comparison slide

Когда важно показать различие между подходами или вариантами.

### 4. Three supporting points

Когда headline уже сильный, а дальше нужно не размывать мысль, а подкрепить ее
3 короткими опорами.

## Чего избегать

- превращать слайд в стену текста;
- делать 5 одинаково важных блоков;
- вставлять pricing/FAQ-логику туда, где нужен один тезис;
- использовать web-like bento layout без необходимости;
- пытаться "вместить всё" в один экран.

## Быстрый self-check

- Какая здесь одна главная мысль?
- Что увидят первым?
- Сколько элементов реально борются за внимание?
- Если убрать 30% содержимого, станет ли слайд сильнее?

Если да, значит слайд ещё перегружен.
