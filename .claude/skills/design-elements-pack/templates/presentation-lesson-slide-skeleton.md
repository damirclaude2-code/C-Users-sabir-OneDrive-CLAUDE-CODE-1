# Presentation Lesson Slide Skeleton

Используй этот skeleton для учебного, explanatory или lesson slide.

## Базовый маршрут

1. Main claim
2. Supporting explanation
3. Visual structure or 3 supporting points
4. Lesson takeaway

## Вариант 1: Claim + 3 points

- headline
- короткое пояснение
- 3 смысловых блока
- нижняя takeaway strip

## Вариант 2: Path / flow slide

- headline
- route row / path row
- 3-4 смысловых блока
- takeaway strip

## Что важно

- headline должен вести слайд;
- supporting text не должен лезть в край;
- route row не должен быть тесным;
- takeaway strip должна закреплять мысль, а не повторять headline слово в слово.
