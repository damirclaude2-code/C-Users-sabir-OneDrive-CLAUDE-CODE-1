# Comparison Page Skeleton

Используй этот skeleton, когда нужно сравнить варианты и помочь выбору.

## Базовый маршрут

1. Headline
2. Когда какой вариант подходит
3. Comparison table
4. Key differentiator block
5. CTA

## Что важно

- не делай comparison page как спор ради спора;
- помоги человеку понять fit;
- таблица должна уменьшать doubt, а не увеличивать;
- после comparison должен быть понятный следующий шаг.
