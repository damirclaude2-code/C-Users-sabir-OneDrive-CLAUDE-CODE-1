# Landing Page Skeleton

Используй этот skeleton, когда нужен лендинг с нуля.

## Базовый маршрут

1. Hero
2. Proof strip
3. Problem block
4. Solution block
5. Value props
6. How it works
7. Testimonials / case proof
8. FAQ
9. Final CTA

## Что должно быть в каждом блоке

### Hero

- что это;
- для кого;
- чем полезно;
- один главный CTA.

### Proof strip

- логотипы;
- цифры;
- короткое доверительное подкрепление.

### Problem block

- знакомая боль;
- язык аудитории;
- без длинного драматического вступления.

### Solution block

- как именно работает решение;
- почему подход отличается;
- что меняется после использования.

### Value props

- 3-4 выгоды;
- каждая отдельна и сканируема.

### FAQ

- снять friction;
- ответить на типовые возражения.

### Final CTA

- конкретный следующий шаг;
- не новый оффер, а завершение маршрута.
