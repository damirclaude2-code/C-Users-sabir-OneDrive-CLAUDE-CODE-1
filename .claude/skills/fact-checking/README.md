# Fact Checking

Навык для строгой проверки фактов и risky claims.

## Подходит для

- цифр и статистики;
- дат;
- сравнений;
- обещаний;
- рыночных тезисов;
- материалов, где можно случайно завысить правду.

## Когда особенно полезен

- текст уже написан, но ему нельзя слепо доверять;
- есть цифры или обещания результата;
- нужны свежие данные;
- ошибка ударит по доверию.

## Примеры вызова

```text
Используй fact-checking и проверь этот текст: какие утверждения здесь можно
оставить, а какие нужно ослабить или переписать.
```

```text
Проверь, не опирается ли этот оффер на неподтвержденные цифры и обещания.
```
