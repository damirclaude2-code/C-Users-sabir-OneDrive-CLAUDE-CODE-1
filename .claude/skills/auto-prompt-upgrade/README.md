# Auto Prompt Upgrade

Этот навык нужен, чтобы Claude Code сначала улучшал слабую постановку задачи, а уже потом выполнял ее.

## Как вызывать

Примеры:

```text
автоулучши запрос:
Сделай отчет по этим файлам.
```

```text
auto update prompt:
Improve the design of this presentation.
```

## Что должно происходить

Claude Code не должен сразу бросаться выполнять задачу.
Сначала он должен:

1. объяснить, чего не хватает;
2. описать эталон хорошего результата;
3. собрать улучшенный запрос;
4. предложить следующий шаг.

## Smoke test на файле из прошлого урока

```text
автоулучши запрос:
Улучши дизайн презентации в файле demo-4-2/presentation-3-3.pdf
```

Если в корне проекта есть `CLAUDE.md`, добавь в него такой короткий блок.
Не дублируй его, если похожее правило уже есть:

```md
## Auto Prompt Upgrade

Если пользователь пишет "автоулучши запрос", "улучши промпт", "auto update prompt" или дает слишком короткую задачу, сначала улучшай постановку задачи, а уже потом предлагай выполнение.
```

## Что показать после установки

После того как ты создал и обновил файлы:

1. Покажи список созданных и обновленных файлов.
2. Коротко объясни, что навык установлен.
3. Покажи одну готовую команду, которой студент может пользоваться дальше.
4. Если найден `demo-4-2/presentation-3-3.pdf`, сразу покажи smoke test на этом файле.

## Критерий успеха

Установка считается хорошей, если после одного сообщения студенту больше не
нужно:

- копировать текст между файлами;
- вручную создавать папки;
- вручную править `SKILL.md`;
- вручную дописывать правило в `CLAUDE.md`.
