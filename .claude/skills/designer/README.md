# Designer

Навык для улучшения уже существующей визуальной подачи.

## Подходит для

- слайдов;
- страниц;
- экранов;
- интерфейсов;
- схем;
- dashboard-блоков.

## Когда особенно полезен

- визуально шумно;
- всё спорит за внимание;
- экран выглядит generic;
- непонятно, что главное;
- нужны конкретные дизайн-правки, а не абстрактные слова.

## Примеры вызова

```text
Используй designer и скажи, что в этом слайде мешает считыванию и как именно его
переделать.
```

```text
Помоги улучшить первый экран страницы: сейчас он выглядит перегруженно и не
объясняет продукт.
```
