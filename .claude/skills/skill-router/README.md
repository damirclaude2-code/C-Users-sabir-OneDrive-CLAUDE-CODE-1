# Skill Router

Навык для выбора правильного рабочего режима.

⚠ **С 2026-08-30 работает автоматически на каждом запросе**, не только по
команде "use skills". Полный русскоязычный словарь слов и фраз, по которым
происходит автовыбор — в `trigger-dictionary.md` рядом с этим файлом.

## Подходит для

- неочевидных задач;
- запросов с несколькими фазами;
- ситуаций, где нужно понять, какой skill звать первым;
- **любого обычного запроса** — молча, без объявления, если совпадение с
  навыком очевидно по словарю.

## Когда особенно полезен

- пользователь пишет "use skills" (но теперь это не обязательно);
- непонятно, что здесь важнее: текст, факты, дизайн или web research;
- нужно коротко назвать рабочий маршрут перед стартом.

## Примеры вызова

```text
Используй skill-router и выбери лучший маршрут навыков для этой задачи.
```

```text
Примени навыки: мне нужно улучшить страницу, но часть тезисов там может быть
устаревшей.
```
