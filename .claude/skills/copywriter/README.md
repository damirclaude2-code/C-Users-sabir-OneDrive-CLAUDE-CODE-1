# Copywriter

Навык для прикладных текстов, которые должны быстро доносить мысль и вести к
действию.

## Подходит для

- лендингов;
- писем;
- постов;
- офферов;
- CTA;
- описаний услуг.

## Когда особенно полезен

- текст сырой;
- смысл размыт;
- нужно сделать оффер понятнее;
- нужно переписать AI-текст в человеческий.

## Примеры вызова

```text
Используй copywriter и перепиши этот блок лендинга так, чтобы было сразу понятно,
что именно мы продаем и зачем это предпринимателю.
```

```text
Подготовь письмо после созвона: коротко, по делу, с понятным следующим шагом.
```
