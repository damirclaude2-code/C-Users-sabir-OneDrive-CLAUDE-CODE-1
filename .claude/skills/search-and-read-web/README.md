# Search And Read Web

Этот навык нужен, чтобы Claude Code умел искать свежие источники и читать сайты
через Tavily и Firecrawl.

## Что делает Tavily

Tavily помогает найти источники по теме.

## Что делает Firecrawl

Firecrawl помогает прочитать конкретную страницу и вытащить из нее содержимое.

## Когда это нужно

Когда вопрос зависит от того, что уже могло измениться:

- цена;
- правило;
- новость;
- страница конкурента;
- актуальные возможности сервиса.

## Пример запроса

```text
Проверь через поиск и чтение сайтов:
какие инструменты сейчас используют AI-агенты для поиска свежей информации и чтения веб-страниц.
```
